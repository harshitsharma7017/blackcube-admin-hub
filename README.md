# BlackCube Admin Hub

Build the BlackCube Manage Data Panel as the production-quality frontend specified in the attached PRD, technical architecture, and UX/UI documents. Read all three documents first, then implement incrementally with Vite, React, TypeScript, Tailwind CSS, React Router, TanStack Query, and Axios only. Frontend only: use a typed mock service/API abstraction designed for the stated future Express + Mongoose REST API. Follow every requirement and acceptance check, including responsive and accessible Manage Data, dialogs, upload wizard, state handling, and production build verification.
